# Commandes rapides pour GitHub

Copie-colle ces commandes dans PowerShell/Terminal pour pousser ton projet sur GitHub.

## Étape 1: Initialiser et faire le premier commit

```powershell
cd c:\wamp64\www\IncisalPDL\htdocs
git init
git add .
git commit -m "Initial commit: Incisal P.D.L - React + Node with 3D animations"
```

## Étape 2: Configurer ton repo GitHub distant

**⚠️ Remplace USERNAME et REPO_NAME !**

```powershell
git remote add origin https://github.com/USERNAME/REPO_NAME.git
```

Exemple avec les vrais noms:
```powershell
git remote add origin https://github.com/hamzamachnaoui/incisal-pdl.git
```

## Étape 3: Renommer main et pousser

```powershell
git branch -M main
git push -u origin main
```

**Attention**: Si tu utilises HTTPS, tu seras demandé d'entrer un Personal Access Token à la place du mot de passe.
Crée un token ici: https://github.com/settings/tokens

---

## Pour les commits suivants

```powershell
git add .
git commit -m "Ton message ici"
git push origin main
```

---

## Vérifier le statut

```powershell
git status          # Fichiers modifiés
git log --oneline   # Historique
git remote -v       # URL du repo distant
```
